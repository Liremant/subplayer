## 1. Что это за проект

Личный видеоплеер: свои файлы, двойные субтитры, панель реплик, поиск, сдвиг тайминга.
Один пользователь, один сервер, локальная сеть. Требования и границы — в
[SPEC.md](SPEC.md); это единственный источник истины о том, **что** должно быть. Здесь —
о том, **как** это делать.

```
src/                 Rust-бэкенд (axum)
  main.rs            роуты, статика, SPA-fallback
  library.rs         скан media/ → movies + series, meta.json, вывод из пути
  mp4.rs             длительность из moov/mvhd
  store.rs           settings.json / progress.json, клампы, атомарная запись
  posters.rs         поиск обложек (TVmaze, iTunes) и скачивание
web/src/             React 19 + Vite 8 + TypeScript
  App.tsx            роутинг: / · /s/:series · /w/:item · /settings
  Catalog.tsx        сетка карточек, фильтры, сортировка
  Series.tsx         страница сериала, эпизоды по сезонам
  Player.tsx         сборка плеера: скин, оверлей, панель, хоткеи
  PlayerKeys.tsx     все горячие клавиши (по event.code)
  PlayerSettings.tsx панель настроек внутри плеера
  SubtitleOverlay.tsx  две строки поверх видео, перетаскивание
  SubtitleList.tsx   боковая панель реплик
  FloatingPanel.tsx  колонка реплик в фуллскрине
  StageShell.tsx     контейнер, который уходит в фуллскрин
  subtitle.ts        парсинг VTT/SRT, поиск по кью
  useCenterActive.ts центрирование активной реплики
scripts/             импорт и склейка субтитров (python + bash)
```

## 2. Git: одна фича — одна ветка

**Никогда не коммитить прямо в `main`.** Одна фича = одна ветка = один PR/мерж.

```sh
git switch -c feat/subtitle-drag     # от свежего main
# … работа, мелкие коммиты по ходу …
git switch main && git merge --no-ff feat/subtitle-drag
git branch -d feat/subtitle-drag
```

- Имя ветки: `feat/…`, `fix/…`, `chore/…`, `docs/…`. Тема — через дефис, по-английски.
- Одна ветка — одна законченная вещь. Две несвязанные правки в одной ветке — это две ветки.
- Мерж в `main` — только когда фича работает целиком и проверена (см. §5).
- `main` в любой момент должен собираться и запускаться.
- Коммит-сообщение: `<область>: <что сделано>`, повелительное наклонение, без точки.
  `player: hold subtitle highlight through cue gaps`, `library: group episodes into series`.
- Не пушить `main` в обход ветки, даже если «правка на одну строку».

## 3. Жёсткие ограничения проекта

Это не вкусовщина — нарушение ломает уже проверенное поведение.

### Субтитры

- **Один файл на эпизод**, в каждой реплике оба языка, оригинал в `<b>`.
  Не два трека, не два файла рядом. Причина в SPEC.md: разные языки нарезаны по-разному.
- **Парсит только клиент** (`web/src/subtitle.ts`). Rust субтитры не разбирает и отдаёт файл
  как есть. Два парсера одного формата неизбежно разойдутся.
- **Нативный `<track>` не использовать.** Он не даёт две строки, свой размер, сдвиг и подсветку.
- Сдвиг тайминга — главная фича. Любая правка оверлея обязана сохранить: режимы
  `оба/оригинал/перевод/выкл`, сдвиг, размер, свободное позиционирование.
- Тайминги в панели показываются **со сдвигом** (`cue.start + shift`), не сырые.

### Медиа

- Браузер играет только `h264 + aac` в `mp4` с `moov` в начале. Всё остальное — транскод
  (`scripts/import.sh`). Не «оптимизировать» это.
- Раздавать файлы только через `ServeDir`/`ServeFile` из `tower-http`. Он уже отдаёт
  `Range`/206/`Content-Range`. **Руками Range не писать** — перемотка сломается тихо.
- Каталог строится из метаданных, а не из структуры папок. Папка без `meta.json` обязана
  попадать в библиотеку (имя и год выводятся из пути).

### Фронт

- Хоткеи — **только по `event.code`**, не по `event.key`. Скин Video.js регистрирует свои
  по `key` и на русской раскладке не работает; наш слой перехватывает в capture-фазе и
  гасит событие. Не добавлять `Hotkey` из пакета — будет двойное срабатывание.
- Плеер — один экран на десктопе (`height: 100dvh`, `overflow: hidden`). Список реплик
  скроллится внутри. Без этого страница растягивается на десятки тысяч пикселей.
- Автоскролл списка — только через `useCenterActive`. `scrollIntoView` прокручивает и
  документ, это уже ломало страницу.

## 4. Стиль кода

- **Меньше кода — лучше.** Не добавлять зависимость ради нескольких строк; в проекте
  стандартная библиотека и уже установленные пакеты закрывают почти всё.
- Бэкенд: без БД, без миграций, без ORM. Состояние — JSON-файлы в `data/`.
- Фронт: без роутер-библиотеки (три маршрута на History API), без стейт-менеджера,
  без UI-кита. Всё, что нужно, — в `styles.css`.
- Комментарий пишется только там, где объясняет **почему**, а не что. Одной строкой.
- Известное ограничение — помечать `shortcut: <предел>, <когда чинить>`.
- Не переименовывать и не «причёсывать» чужие модули по пути. Правка ради правки — это шум.

### Токены и вёрстка

- Цвета и шрифты — только через `var(--…)` из `web/src/styles.css`. Инлайновых hex и
  `oklch()` в компонентах быть не должно.
- Один акцент, нейтрали с его оттенком, без чистого `#000`/`#fff`.
- `font-variant-numeric: tabular-nums` на любых числах, которые меняются.
- Никакой анимации на частотные действия (клик по реплике, хоткеи): только цвет/фон.
  Переход подсветки между репликами — 200 ms, это осознанное исключение.
- Мобильный пол: 320 / 375 / 414 / 768 px без горизонтального скролла.

## 5. Проверка перед мержем

Всё, что ниже, должно проходить. Если проверка не запускалась — так и написать в PR.

```sh
cargo test                                    # бэкенд: скан, парсинг путей, mvhd, store
cd web && npx tsc --noEmit                    # типы
cd web && node --experimental-strip-types src/subtitle.check.ts   # самопроверка парсера
cd web && pnpm build                          # сборка фронта
cargo build --release                         # сборка бинаря
```

Вручную, на реальном эпизоде с настоящими субтитрами:

1. Эпизод появился в каталоге, обложка и прогресс на месте.
2. Играет, обе строки видны, режимы переключаются.
3. Сдвиг ±1.5 с двигает и оверлей, и тайминги в панели.
4. Клик по реплике перематывает ровно туда, что написано.
5. Поиск находит, подсвечивает, Enter переходит.
6. Перезагрузка страницы продолжает с того же места.
7. Фуллскрин: колонка справа, видео не перекрыто, активная реплика по центру.
8. Хоткеи работают с **русской** раскладкой.

## 6. Как запускать локально

```sh
./scripts/demo.sh                 # демо-библиотека (ffmpeg), если media/ пуста
cargo build --release
systemctl --user restart subplayer   # если настроен юнит — он держит :3000
```

Либо вручную: `./target/release/subplayer` (порт 3000, слушает только loopback).
Фронт в разработке: `cd web && pnpm dev` (проксирует `/api` и `/media` на :3000).

**Порт 3000 может держать systemd-юнит** `subplayer.service` с `Restart=always`. Если
`cargo run` падает с `AddrInUse` — это он. Перезапускать через `systemctl --user restart`,
а не убивать процесс.

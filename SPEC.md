# subplayer — что хотим получить

Свой плеер: **моё видео + мои субтитры**, интерфейс уровня [2sub.movie](https://2sub.movie/series/breaking-bad_2008/#watch-s1e1).

Не клон 2sub. Никаких пользователей, каталога переводчиков и paywall.

---

## Что должно быть в итоге (must)

1. **Каталог.** Главное меню: одна сетка вертикальных карточек с обложками. Никаких секций — тип делится только фильтром `Все / Фильмы / Сериалы`. Поиск по названию, сортировка (`последние просмотренные / по алфавиту / недавно добавленные`).
   - На карточке: обложка, название, **строка прогресса** («смотреть с 12:41», «S01E02 · начать», «просмотрено»), отдельной строкой — метаданные (год, тип, длительность).
   - Фильм открывает плеер. Сериал открывает свою страницу.
2. **Страница плеера.**
   - видео играет, перемотка, скорость, громкость, фуллскрин, горячие клавиши;
   - запоминается позиция просмотра (продолжить с места).
3. **Субтитры.**
   - две строки одновременно: оригинал + перевод;
   - режимы: `оригинал` / `перевод` / `оба` / `выкл`;
   - размер текста и позиция;
   - **сдвиг тайминга** вперёд/назад (главное — подгонять чужие субтитры под свой релиз);
   - показ предыдущей реплики (опционально).
4. **Панель субтитров.** Прокручиваемый список всех реплик рядом с видео; клик по реплике → переход на это время; текущая подсвечена и автоскроллится.
5. **Поиск по субтитрам** с подсветкой найденного и переходом к реплике.
6. **Свои файлы.** Кладу `.mp4` + `.vtt`/`.srt` в папку — сервис их видит.
7. **Страница сериала.** Обложка, название, год, сезоны, «просмотрено N из M», кнопка **«Продолжить S01E02 с 12:41»** (последний недосмотренный эпизод, иначе следующий), список эпизодов по сезонам с прогрессом.
8. **Обложки.** Своя картинка кладётся рядом (`poster.jpg`) — работает без сети. Либо кнопка «Обложка» ищет постер по названию в бесплатных источниках без ключа (TVmaze для сериалов, iTunes для фильмов) и скачивает выбранный в `data/posters/`.
9. **Настройки.** Отдельный экран — только то, у чего нет лучшего места: сортировка каталога и скорость по умолчанию. Настройки субтитров живут **в плеере**, в панели «Настройки плеера».

## Чего НЕ делаем (non-goals)

- пользователи, регистрация, роли, права;
- словарь, клик-по-слову, карточки, Anki;
- переводчик-воркфлоу, рейтинг переводов, модерация;
- автоматическая добыча субтитров (Bazarr/subliminal) и ASR;
- каталог фильмов с TMDB, рекомендации;
- транскодинг, адаптивный HLS;
- мобильные приложения, Cast/AirPlay.

Не «никогда», а «не сейчас». Сначала должен работать просмотр.

## Отложено, но заложить возможность

- **word-level подсветка** (караоке по словам) — офлайн-пайплайн, не фича плеера: прогнали файл → сохранили тайминги → плеер их читает. В v1 нет.
- загрузка файлов через UI;
- несколько версий субтитров на эпизод;
- редактирование метаданных через UI (сейчас `meta.json` правится руками);
- описания, рейтинги и прочие метаданные с TVmaze/TMDB — тянем только постер;
- автоскачивание обложек для всей библиотеки разом.

## Ключевое техническое решение

Двойные субтитры **не** делаем двумя треками. Один файл, в каждой реплике оба языка, оригинал помечен `<b>`:

```
1
00:00:01.000 --> 00:00:03.000
<b>I am the one who knocks</b>
Я тот, кто стучится
```

Почему: разные языки нарезаны на реплики по-разному. Склейка двух независимых файлов «по индексу» или «по времени» на реальных данных разваливается. Один файл = один источник истины для нарезки.

Парсит его **только клиент** (`web/src/subtitle.ts`). Rust субтитры не трогает и отдаёт файл как есть — иначе два парсера одного формата расходятся.

## Раскладка

```
media/                     # корень библиотеки, задаётся SUBPLAYER_MEDIA
  Breaking Bad/            # иерархия свободная: как разложил, так и лежит
    S01/
      E01/
        video.mp4
        subs.vtt           # один файл, оба языка
        meta.json          # опционально
      E02/
        video.mp4
        subs.srt
        meta.json
  Dune (2021)/
    video.mp4
    subs.vtt
    meta.json
```

Скан рекурсивный: **любая** папка, где лежит `video.mp4`/`.m4v`/`.webm`, попадает в каталог. Иерархия на диске не обязана совпадать с иерархией в каталоге — каталог строится из метаданных.

Эпизоды **не добавляются по одному в каталог**: они сворачиваются в карточку сериала по имени (`series` из `meta.json`, иначе выведенное из пути). Один сериал = одна карточка на главной, сколько бы папок под него ни лежало.

Обложка сериала ищется в таком порядке: `meta.json` → `poster.*` в папке сериала → `data/posters/<slug>.*` (скачанная). У фильма то же самое, только вместо папки сериала — его собственная папка.

Имена файлов чистятся от scene-мусора: `Dune.2021.1080p.BluRay.x264-GRP` → `Dune`, год `2021`, теги (`1080p`, `x264`, `WEB-DL`, `DDP5.1`…) отбрасываются.

`meta.json` переопределяет то, что выведено из пути; всё отсутствующее выводится из имён папок:

```json
{ "kind": "movie", "title": "Dune", "year": 2021, "duration": 30 }
```

| Поле | Обязательно | Если нет |
|---|---|---|
| `kind` | нет | `episode`, если нашёлся сезон/эпизод в пути, иначе `movie` |
| `title` | нет | имя папки без маркера `S01`/`E02` |
| `series` | нет | `title` |
| `season` / `episode` | нет | из пути: `S01E02`, `1x02`, `S01/E02`, `S01/E02` |
| `year` | нет | пусто |
| `duration` | нет | читается из `moov/mvhd` самого mp4 |
| `poster` | нет | `poster.*` в папке, иначе скачанный постер |

Без БД. Прогресс и настройки — JSON-файлы в `data/` (задаётся `SUBPLAYER_DATA`).

## Стек

- **бэкенд:** Rust — axum 0.8 + tower-http 0.7 (`fs`) + tokio + serde + walkdir.
  `ServeDir`/`ServeFile` уже отдают `Range`/206/416/HEAD/`Content-Length`, поэтому перемотка работает без ручной арифметики.
- **плеер:** Video.js 10 — это пакет `@videojs/react` 10.2.0 (пакет `video.js@10` — пустая заглушка, кидающая ошибки на паттерны v8).
  Plyr и Vidstack в 2026 deprecated в его пользу — проверено по npm `deprecated`-полю.
- **субтитры:** свой DOM-оверлей. Не нативный `<track>` — он не даёт две строки, свой шрифт, сдвиг и подсветку.
  Рендер по `requestAnimationFrame` из распарсенных кью (`timeupdate` тикает ~4 раза/с — это видно глазом).
- **фронт:** React 19 + Vite 8 + TypeScript, без роутер-библиотеки (три маршрута на History API).
- **видео:** `mp4` + HTTP `Range`. HLS не нужен.

## API

| Метод | Путь | Что делает |
|---|---|---|
| GET | `/api/library` | `{ movies, series }`; у каждого эпизода свой прогресс |
| GET | `/api/settings` | глобальные настройки (включая `sort`) |
| PUT | `/api/settings` | сохранить настройки (значения клампятся) |
| POST | `/api/progress` | `{ id, t, dur, shift }`; сервер ставит `updated` |
| GET | `/api/posters/search?kind=&q=` | кандидаты обложек (TVmaze / iTunes) |
| POST | `/api/posters` | `{ kind, id, url }` → скачивает в `data/posters/` |
| GET | `/media/<path>` | файлы с `Range` |
| GET | `/posters/<file>` | скачанные обложки |

`id` материала — путь папки относительно `media/` (`Breaking Bad/S01/E01`), он же ключ прогресса. `shift` в прогрессе — сдвиг конкретного релиза, он важнее глобального.

## Как запустить

```sh
./scripts/demo.sh          # демо-библиотека (ffmpeg), или кладём свои файлы в media/
cargo run                  # http://127.0.0.1:3000
cd web && pnpm install && pnpm build   # или pnpm dev (проксирует /api и /media на :3000)
```

Переменные: `SUBPLAYER_MEDIA` (по умолчанию `media`), `SUBPLAYER_DATA` (`data`), `SUBPLAYER_DIST` (`web/dist`), `SUBPLAYER_PORT` (`3000`).

## Горячие клавиши

`Space` пауза · `←`/`→` ±5 с · `↑`/`↓` громкость · `m` mute · `f` фуллскрин · `[`/`]` сдвиг субтитров ∓0.5 с · `c` режим субтитров.

## Как поймём, что готово

1. Кинул папку с `video.mp4` + `subs.vtt` → она появилась в библиотеке.
2. Открыл → играет, обе строки видны, режимы переключаются.
3. Сдвинул тайминг на −1.5 с → субтитры встали ровно.
4. Кликнул реплику в панели → видео перескочило на неё.
5. Нашёл слово поиском → перешёл к реплике.
6. Закрыл, открыл заново → продолжило с того же места.

## Что проверено, а что нет

Проверено: все пункты выше на реальном mp4 и на враждебных данных (длинные названия, эмодзи, RTL-субтитры, реплика выше кадра, пустой `meta.json`, `duration` = 99999999); `Range`/206; отсутствие горизонтального скролла на 320/375/414/768 px; отказ path traversal в `/media/..`; поиск и скачивание обложек из обоих источников; сортировка (клик и клавиатура) с сохранением на сервере; юнит-тесты `cargo test` (скан и свёртка в сериал, чистка scene-имён, общий родитель, `mvhd`, клампы настроек, битый JSON, slug) и самопроверка парсера (`node --experimental-strip-types web/src/subtitle.check.ts`).

Не проверено: Safari/iOS (фуллскрин там только видео — DOM-оверлей в него не композитится, это ограничение платформы, а не кода); воспроизведение файлов без `faststart` (перемотка будет рваной — сервер этого не лечит, `moov` должен быть в начале файла).
